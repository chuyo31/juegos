# Chuyo Games

Portal estático de juegos publicado en GitHub Pages.

## Añadir un juego

Editar `games.json` y añadir un objeto con:

- `id`
- `name`
- `version`
- `category`
- `platform`
- `status`
- `playUrl`
- `downloadUrl`
- `cover`
- `description`
- `tags`
- `featured`

No es necesario modificar `index.html` ni `app.js` para añadir una nueva ficha.


## Repair Mahjong integrado
